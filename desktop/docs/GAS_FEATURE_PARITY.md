# GAS Feature Parity

Linux版の最低ラインは、GAS版メニューで運用上使っていた機能に同等の入口と処理を持つこと。

## 勤務表運用

| GAS機能 | Linux版状態 | 対応 |
| --- | --- | --- |
| 月次切替をまとめて実行 | 未実装 | アーカイブ、次月作成、運用月更新のローカル実装が必要 |
| 作成対象月の勤務表を作成 / 再作成 | 対応中 | Solver実行、診断表示、保存に対応 |
| 手修正後の再判定 | 一部対応 | 入力確認と診断はあるが、手修正専用の再判定入口を追加する |
| 印刷 / PDF用に勤務表を整える | 対応中 | PDF/HTML出力あり。GAS相当のレイアウト精度を継続調整 |
| 初期設定をまとめて実行 | 一部対応 | 空ドキュメント生成あり。GASのシート初期化相当はローカル初期化フローへ整理 |
| 勤務表カレンダーを修復 | 一部対応 | 年月・日数更新は可能。専用修復ボタンが必要 |
| 運用状況表示を更新 | 一部対応 | サマリー表示あり。運用月/作成対象月/保存済み月の表示が必要 |
| 月次切替前チェック | 未実装 | GASの `buildMonthlyTransitionPrecheck_` 相当を実装する |
| 不要タブを整理 / 内部タブ保護 | 対象外寄り | ローカルアプリではタブ保護ではなくデータ領域の整理として扱う |
| 職員一覧の列を自動追加 / プルダウン修復 | 一部対応 | TSV/表表示あり。入力フォーム化で代替する |
| Solver接続を確認 | 一部対応 | 内蔵Solverの存在チェックあり。UI入口が必要 |
| Solver入力JSONをDriveに作成 | 対応中 | JSONエクスポートあり。GAS入力形式でのエクスポート入口が必要 |
| Solver結果JSONをDriveから取り込み | 一部対応 | GAS入力JSON取り込みは対応。Solver出力JSON取り込み入口が必要 |
| 体制シミュレーションを再計算 / 表示更新 / 取り込み | 未実装 | GASの capacity simulation 相当をLinux側へ移植する |
| AI向け出力を作成 | 未実装 | ローカル診断バンドル出力として実装する |
| 旧改善提案を作成 | 未実装 | 診断/修正候補として置き換える |

## 休暇・急休

| GAS機能 | Linux版状態 | 対応 |
| --- | --- | --- |
| 休暇・希望勤務を入力 | 一部対応 | TSV編集あり。フォーム入力が必要 |
| 急休リカバリーを実行 | 対応中 | 急休TSVからSolverリカバリー可能 |
| 急遽休を取り消し | 未実装 | 急休履歴モデルと取消処理が必要 |
| 事前休暇を取り消し | 一部対応 | TSVから削除可能。専用操作が必要 |
| 勤務実績シートを作成 / 更新 | 未実装 | 勤務表から実績データを複製するモデル/出力が必要 |
| 変更履歴の自動記録 | 未実装 | ローカル操作履歴を保存する必要 |

## 出力

| GAS機能 | Linux版状態 | 対応 |
| --- | --- | --- |
| Excel / PDF出力 | 対応中 | 既存 |
| JSON / TSV入出力 | 対応中 | 既存 |
| 各スタッフの送信用テキストを作成 | 対象外 | Linux版では実装しない |
