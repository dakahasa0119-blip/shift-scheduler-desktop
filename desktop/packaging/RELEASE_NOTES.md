# 勤務表作成アプリ リリースノート

## shift-scheduler-linux-x64 / shift-scheduler-windows-x64

このリリースは、GAS版の勤務表作成をローカルPCで動かすための配布版です。

含まれるもの:

- ローカルブラウザ画面
- 同梱Node.js runtime
- 同梱Solver実行ファイル
- 勤務表作成
- 入力確認
- 急休リカバリー
- 休暇・希望勤務の登録
- 事前休暇取消
- 急遽休取消
- 勤務実績作成
- 変更履歴、急休履歴
- 月次切替前チェック
- 月次アーカイブ、次月勤務表作成、運用月更新
- 月次切替まとめて実行
- 勤務表カレンダー修復
- 体制シミュレーション
- Solver入力JSON出力
- Solver結果JSON取り込み
- AI向け出力
- 保存、読込、バックアップ
- Excel出力
- PDF出力

注意:

- Windows版はWindows上で最終起動確認を行ってから配布してください。
- コード署名とインストーラーは未対応です。
- 初回起動時は空の勤務表データから始まります。GAS版のSolver入力JSON、職員TSV、希望TSVを取り込んで運用データを作成してください。
- 各スタッフへの送信機能は含めていません。
