# 勤務表作成アプリ リリースノート

## shift-scheduler-linux-x64 / shift-scheduler-windows-x64

このリリースは、GAS版の勤務表作成をローカルPCで動かすための配布版です。

含まれるもの:

- ローカルブラウザ画面
- 同梱Node.js runtime
- 同梱Solver実行ファイル
- 勤務表作成
- 入力確認
- 急休リカバリー
- 保存、読込、バックアップ
- Excel出力
- PDF出力

注意:

- Windows版はWindows上で最終起動確認を行ってから配布してください。
- コード署名とインストーラーは未対応です。
- 初回起動時は空の勤務表データから始まります。
