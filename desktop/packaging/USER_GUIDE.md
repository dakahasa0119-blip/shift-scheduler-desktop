# 勤務表作成アプリ 操作ガイド

## 起動

### Windows

`start-shift-scheduler.vbs` をダブルクリックします。

画面が開かない場合は `start-shift-scheduler.cmd` を実行し、表示されたURLをブラウザで開いてください。

### Linux

`start-shift-scheduler.sh` を実行します。

デスクトップメニューに登録する場合は `install-desktop-launcher.sh` を実行してください。

## 基本の流れ

1. `基本設定` で対象年月と必要人数を確認します。
2. `職員` タブに職員一覧を入力します。
3. `希望` タブに希望休・希望勤務を入力します。
4. `入力確認` を押して入力エラーを確認します。
5. 必要に応じて `作成時間` を選び、`勤務表作成` を押します。
6. 右側の `確認事項` で不足、希望未充足、対応候補を確認します。
7. 必要に応じて職員条件、希望、勤務表編集を直し、`手修正後の再判定` を押します。
8. `勤務実績作成` を押して配布後の実績管理用データを作ります。
9. `保存`、`Excel出力`、`PDF出力` を行います。

## 入力形式

職員、希望、勤務表編集欄は表形式の貼り付けに対応しています。Excelやスプレッドシートから範囲をコピーして貼り付けできます。

GAS版から `solver_input_YYYYMM.json` を出力できる場合は、`詳細データ` タブにそのまま貼り付けて `詳細データ反映` を押してください。Apps Script APIで取得した `{ "ok": true, "result": ... }` 形式でも、そのまま取り込めます。アプリ側のデータ形式へ変換して取り込みます。

### 職員

先頭行はヘッダーです。

```text
氏名	職種	性別	雇用	可能勤務	可能曜日	固定休	夜勤目標	夜勤下限	夜勤上限	月勤務上限	公休目標	週勤務上限	週夜勤上限	入職日	退職日	備考
```

`可能勤務` は `早・日・遅・夜` または `早,日,遅,夜` のように入力できます。

`可能曜日` は `月・火・水・木・金・土・日` または `1,2,3,4,5,6,0` のように入力できます。数字の場合は `0=日`、`1=月`、`6=土` です。

### 希望休・希望勤務

```text
氏名	区分	開始日	終了日	備考
```

区分は `事前希望休`、`有給`、`特別休`、`希望早出`、`希望日勤`、`希望遅出`、`希望夜勤` などを使います。

## 急休再調整

`休暇・急休` 欄で `当日急遽休` を登録すると、勤務実績側に急休が反映され、変更履歴と急休履歴に記録されます。

勤務表作成機能で再調整する場合は `急休再調整入力` を開き、対象者と日付を入力して `急休再調整` を押します。

固定終了日は、その日までの勤務をできるだけ動かさないための指定です。

登録済みの急休は `急遽休を取り消し` で元のシフトへ戻せます。事前休暇は `事前休暇を取り消し` で希望データから削除できます。

## 月次運用

`月次切替前チェック` は、対象月、職員、勤務表、診断状態を確認します。

`月次切替まとめて実行` は、現在月の勤務表・勤務実績・希望データ・変更履歴をアーカイブし、次月勤務表を準備し、運用月を更新します。

次月準備時には、前月末7日分の勤務だけを引き継ぎ、希望休・希望勤務は新しい月用に空へ戻します。

分けて実行したい場合は `分割実行・保守` を開いて、次の順で実行できます。

1. `月次アーカイブ`
2. `次月勤務表作成`
3. `運用月更新`

勤務表の日数や対象月が崩れた場合は `勤務表カレンダー修復` を使います。

## 体制シミュレーション

`体制` タブで `体制シミュレーション再計算` を押すと、現在の職員条件と必要人数から追加職員数の目安を計算します。

結果は画面右側の体制シミュレーション欄と `体制` タブで確認できます。外部で作成した結果データは `体制結果取り込み` で反映できます。

## 作成データ

`作成データ` タブでは、現在の入力から作成される勤務表作成用データを確認できます。

別環境で作成した結果データがある場合は、`作成結果データ` に貼り付けて `作成結果取り込み` を押すと勤務表へ反映できます。

`作成機能確認` は、同梱の勤務表作成機能を呼び出せる状態か確認します。

`作成時間` の既定値はGAS版と同じ `4分` です。職員数や希望条件が多い月は、右側の `作成時間` を `10分`、`20分`、`30分` に上げて再実行できます。

## 調査用データ出力

`調査用データ出力` は、勤務表、職員条件、希望、診断、履歴をまとめた確認用データを出力します。問題調査や改善相談に使います。

## 保存と読込

`保存` は現在の入力と勤務表をアプリのデータフォルダへ保存します。  
`読込` は保存済みデータを開きます。  
`バックアップ` は現在の状態を別ファイルとして保存します。

`変更履歴` と `急休履歴` は `履歴` タブから確認できます。サポート時には、バックアップ、調査用データ、履歴出力を確認してください。

## 終了

画面右上の `終了` を押すとアプリのローカルサーバーが停止します。終了画面が出たらブラウザタブを閉じてください。
