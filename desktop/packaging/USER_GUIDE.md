# 勤務表作成アプリ 操作ガイド

## 起動

### Windows

`start-shift-scheduler.vbs` をダブルクリックします。

画面が開かない場合は `start-shift-scheduler.cmd` を実行し、表示されたURLをブラウザで開いてください。

### Linux

`start-shift-scheduler.sh` を実行します。

デスクトップメニューに登録する場合は `install-desktop-launcher.sh` を実行してください。

## 基本の流れ

1. `基本設定` で対象年月と必要人数を確認します。
2. `職員` タブに職員一覧を入力します。
3. `希望` タブに希望休・希望勤務を入力します。
4. `入力確認` を押して入力エラーを確認します。
5. `勤務表作成` を押します。
6. 右側の確認事項を見て、必要に応じて入力を直します。
7. `Excel出力` または `PDF出力` で保存します。

## 入力形式

職員、希望、勤務表はTSV形式です。Excelやスプレッドシートから範囲をコピーして貼り付けできます。

GAS版から `solver_input_YYYYMM.json` を出力できる場合は、`JSON` タブにそのまま貼り付けて `JSON反映` を押してください。アプリ側のデータ形式へ変換して取り込みます。

### 職員

先頭行はヘッダーです。

```text
氏名	職種	性別	雇用	可能勤務	可能曜日	固定休	夜勤目標	夜勤下限	夜勤上限	月勤務上限	公休目標	週勤務上限	週夜勤上限	入職日	退職日	備考
```

`可能勤務` は `早・日・遅・夜` のように入力します。

### 希望休・希望勤務

```text
氏名	区分	開始日	終了日	備考
```

区分は `事前希望休`、`有給`、`特別休`、`希望早出`、`希望日勤`、`希望遅出`、`希望夜勤` などを使います。

## 急休リカバリー

`急休` 欄に対象者と日付を入力し、必要なら固定終了日を指定して `急休リカバリー` を押します。

固定終了日は、その日までの勤務をできるだけ動かさないための指定です。

## 保存と読込

`保存` は現在の入力と勤務表をアプリのデータフォルダへ保存します。  
`読込` は保存済みデータを開きます。  
`バックアップ` は現在の状態を別ファイルとして保存します。

## 終了

画面右上の `終了` を押すとアプリのローカルサーバーが停止します。終了画面が出たらブラウザタブを閉じてください。
